Ruleset changes affect ALL campaigns.
Savefile changes only affect the save you open.

Ruleset Editor

Edits the game's rules: characters, items and ability cards.

Open your ruleset with File → Open Ruleset. The file is called Base.ruleset and is stored in:

...\Steam\steamapps\common\Frosthaven\Frosthaven_Data\StreamingAssets\Rulebase

Make your changes in the menus above, then save with File → Save Ruleset. Saving also closes the ruleset.

Savefile Editor

Edits one campaign save: gold and materials for each character, plus the town's herbs and stats (morale, prosperity, soldiers, defense).

Open a save with File → Open Savefile. The saves are called AutoSave_<number>.dat and are stored in:

...\AppData\LocalLow\Snapshot Games Inc\Frosthaven\Steam\<steam_id>\Campaign\<party_name>

Edit the values in the town and character tabs, then click Save & Close. Close the game before saving.

Backups

The first time you open a file, a backup of the original is created automatically: the ruleset backup goes in the "original ruleset" folder and can be restored with File → Restore Original; the savefile backup is placed next to the save file with a .bak extension. You can also create manual ruleset backups with File → Create Backup.

One file at a time

Only one file can be open at a time. Save or close the current ruleset/savefile before opening the other. If something doesn't work, check More → Troubleshooting.
